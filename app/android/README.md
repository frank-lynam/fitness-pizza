# Android APK

Place the built APK here as `fitness-pizza.apk`.

After building (see `BUILD.md`), copy from:
```
android/app/build/outputs/apk/release/app-release.apk
```
to:
```
app/android/fitness-pizza.apk
```

The APK is then served at `https://fitness-pizza.com/app/android/fitness-pizza.apk`
and linked from the Settings → Help & Feedback section inside the app.
